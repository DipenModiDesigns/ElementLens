Download latest release

Chrome, Edge, Brave, Opera, Vivaldi

  1. Download element-lens-…-chrome.zip from the release and unzip it.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the unzipped folder.

Firefox

  1. Download element-lens-…-firefox.zip from the release.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and choose the zip file.

Firefox removes temporary add-ons when it restarts. A permanent install comes with the Firefox Add-ons listing.

Using it

Click the ElementLens icon in the toolbar (pin it first) or press Alt+Shift+E. Hover over the page, click an element, then copy. Press Esc to close.

FAQ

Questions.

Is it really free?

Yes. No paid tier, no ads, no account.

Which browsers are supported?

Chrome, Edge, Brave, Opera and Vivaldi (all Chromium), and Firefox 140 or newer. Safari is planned.

Does it copy JavaScript too?

Not yet. Event handlers and framework components (React, Vue, jQuery) are coming soon. Note that browsers never let extensions read listeners added with addEventListener, so that part will always be partial.

Why is some CSS missing in "Site rules"?

Browsers block reading stylesheets loaded from other domains. ElementLens tells you how many it had to skip. The "CSS" format always shows the full computed result.

Does the Tailwind output include hover and responsive variants?

If the page already uses Tailwind, its original classes are kept, including variants. Otherwise classes are generated from the current computed styles, which only show the current state.

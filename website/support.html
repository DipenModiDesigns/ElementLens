Troubleshooting

Nothing happens when I click the icon

Browsers block all extensions on their own pages (chrome://, about:, the extension stores, the built-in PDF viewer). The icon briefly shows a red "!" there. Try a normal website.

The shortcut Alt+Shift+E does not work

Another extension may use it. Change it at chrome://extensions/shortcuts (Edge: edge://extensions/shortcuts, Firefox: Add-ons > gear icon > Manage Extension Shortcuts).

"Site rules" shows fewer rules than expected

Stylesheets loaded from other domains (for example a CDN) cannot be read by extensions. The panel says how many were skipped. Switch to the "CSS" style format for the full computed result.

The copied code looks different from the page

Computed styles describe the current state only: hover effects, animations and other screen sizes are not included. "Site rules" keeps :hover and @media rules. Content inside iframes from other domains and closed shadow DOM cannot be read.

The panel is off screen or too wide

Open the ElementLens settings (right-click the icon > Options) and use "Reset panel position".

Known limits

  • JavaScript extraction is coming soon. Browsers never expose listeners added with addEventListener to extensions.
  • Tailwind classes generated from computed styles cannot include hover or responsive variants.
  • Elements inside cross-origin iframes cannot be picked yet.
